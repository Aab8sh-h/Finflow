# FinFlow

A personal finance REST API built with Python, FastAPI, and PostgreSQL.

## Project Goals

- Secure user authentication and authorization
- Account and transaction management
- Budget tracking
- Financial reporting and summaries
- Automated testing and continuous integration

## Technology Stack

- Python 3.13
- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- Pytest
- Docker
